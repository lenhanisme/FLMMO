Tài liệu tích hợp API

Chào mừng bạn đến với tài liệu API của FLMMO.VN. API của chúng tôi cho phép bạn tự động hóa việc đặt hàng, kiểm tra trạng thái và quản lý số dư ngay trên hệ thống website của riêng bạn. API được thiết kế theo tiêu chuẩn RESTful đơn giản, dễ dàng đấu nối với mọi ngôn ngữ lập trình (PHP, Python, Node.js,...).

URL API Gốc (Base URL)

https://flmmo.vn/api/v1

Tất cả các request đều sử dụng phương thức POST và định dạng dữ liệu trả về là JSON.

Xác Thực (Authentication)

Mọi yêu cầu gửi lên API đều yêu cầu phải có một API Key hợp lệ. Bạn cần truyền API Key này vào body của request dưới dạng tham số key.

Cấu trúc chung 
{
  "key": "YOUR_API_KEY_HERE",
  "action": "tên_hành_động"
}

Mẹo: Đăng nhập vào trang Dashboard -> Tài liệu API để lấy API Key riêng của bạn.

Mã nguồn mẫu (Code Examples)

Dưới đây là một số ví dụ để bạn có thể sao chép và sử dụng ngay lập tức.

PHP (cURL) 
<?php
$url = 'https://flmmo.vn/api/v1';
$data = [
    'key' => 'your-api-key',
    'action' => 'services'
];

$ch = curl_init($url);
curl_setopt($ch, CURLOPT_POST, 1);
curl_setopt($ch, CURLOPT_POSTFIELDS, http_build_query($data));
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$response = curl_exec($ch);
curl_close($ch);

$result = json_decode($response, true);
print_r($result);
?>
Python (Requests) 
import requests

url = "https://flmmo.vn/api/v1"
data = {
    "key": "your-api-key",
    "action": "services"
}

response = requests.post(url, data=data)
print(response.json())

1. Lấy danh sách dịch vụ

Truy xuất danh sách tất cả các dịch vụ đang có sẵn và đang hoạt động trên hệ thống.

Tham số gửi đi (Request Parameters)

Tham SốMô Tả
keyAPI Key của bạn
actionBắt buộc là: services

Ví dụ Phản hồi (JSON Response)

[
  {
    "service": 1,
    "name": "Tăng Follow Facebook [Siêu tốc]",
    "category": "Facebook",
    "rate": "5000",
    "min": "100",
    "max": "100000"
  }
]

2. Tạo đơn hàng mới

Gửi yêu cầu tạo một đơn hàng mới (tăng like, follow, view...) vào hệ thống.

Tham số gửi đi (Request Parameters)

Tham SốMô Tả
keyAPI Key của bạn
actionBắt buộc là: add
serviceID của dịch vụ (Lấy từ bảng dịch vụ)
linkLink bài viết hoặc UID cần tăng
quantitySố lượng cần tăng

Ví dụ Phản hồi Thành Công

{
  "order": 92842,
  "message": "Tạo đơn hàng thành công"
}

Ví dụ Phản hồi Lỗi (Thiếu tiền, sai link)

{
  "error": "Tài khoản của bạn không đủ số dư để thực hiện giao dịch."
}

3. Kiểm tra trạng thái đơn

Kiểm tra tiến độ chạy của một đơn hàng cụ thể.

Tham số gửi đi (Request Parameters)

Tham SốMô Tả
keyAPI Key của bạn
actionBắt buộc là: status
orderID của đơn hàng (Được trả về lúc tạo đơn)

Ví dụ Phản hồi

{
  "charge": "5000",
  "start_count": "1250",
  "status": "In progress", // Pending, In progress, Completed, Canceled
  "remains": "300"
}

4. Kiểm tra số dư

Lấy số dư hiện tại của tài khoản của bạn (Đơn vị: VNĐ).

Tham số gửi đi (Request Parameters)

Tham SốMô Tả
keyAPI Key của bạn
actionBắt buộc là: balance

Ví dụ Phản hồi

{
  "balance": "150000",
  "currency": "VND"
}
