API Documentation v2.0

Chào mừng bạn đến với tài liệu API của FLMMO.VN. API của chúng tôi cho phép các hệ thống SMM Panel khác, hoặc các mã nguồn tự động kết nối và mua dịch vụ trực tiếp một cách lập trình (Programmatic).

Phương thức kết nối (HTTP Method)

Toàn bộ API của FLMMO.VN đều sử dụng phương thức POST. Dữ liệu bắt buộc được truyền theo định dạng application/x-www-form-urlencoded.

Xác Thực (Authentication)

Mọi yêu cầu (request) gửi tới máy chủ đều phải chứa tham số key. Đây chính là API Key bí mật của bạn.

Bạn có thể tạo và lấy mã API Key này tại mục Profile (Hồ sơ) trên trang chủ FLMMO.VN.

Base API URL
https://flmmo.vercel.app/api/v2
POST

Lấy danh sách dịch vụ

Parameters (Tham số)

ParameterTypeBắt buộcMô tả
keyStringCóAPI Key của bạn
actionStringCóNhập services

Example Request (PHP)

$api_url = "https://flmmo.vercel.app/api/v2";
$data = [
    'key' => 'flmmo_your_api_key_here',
    'action' => 'services'
];

$ch = curl_init($api_url);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, http_build_query($data));
$response = curl_exec($ch);
curl_close($ch);

echo $response;

Tạo Đơn Hàng Mới

Parameters

ParameterTypeBắt buộcMô tả
keyStringCóAPI Key của bạn
actionStringCóNhập add
serviceIntegerCóID của dịch vụ (Lấy từ hàm services)
linkStringCóLink bài viết / trang cá nhân cần tăng
quantityIntegerCóSố lượng cần tăng

Example Python (Requests)

import requests

url = "https://flmmo.vercel.app/api/v2"
data = {
    "key": "flmmo_your_api_key_here",
    "action": "add",
    "service": 1,
    "link": "https://facebook.com/12345",
    "quantity": 1000
}

response = requests.post(url, data=data)
print(response.json())
